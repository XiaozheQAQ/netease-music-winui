  Both faces expose 31,032 glyphs and 30,887 Unicode mappings.
  CJK Unified Ideographs U+4E00-U+9FFF: 20,976 mapped characters.
  Hiragana U+3040-U+309F: 93 mapped characters.

  CN is the upstream broad Chinese/Japanese subset; Hangul is not included.
  Characters outside this font's coverage use the platform's normal font fallback.

Controls/LyricTypography.cs loads these static faces via ms-appx URIs; no system
font installation, runtime font download, variable font, or synthetic bold is used.
Primary and timed lyrics use Heavy; romanization, translation and track metadata
can use Bold for a lighter hierarchy while retaining the rounded shape.
